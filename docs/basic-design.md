# 제습기 기본설계서

## 1. 개요

### 1.1 개발 목적

펠티어 소자를 이용하여 주변 공기의 습도를 제거할 수 있는
소형 제습기를 제작한다.

제습기의 기본적인 제어 기능을 구현하고,
향후 IoT 시스템과 연동할 수 있도록 확장 가능한 구조로 설계한다.

### 1.2 제습기 개요

본 시스템은 펠티어 소자의 냉각 효과를 이용하여
공기 중의 수분을 응축시키는 방식의 제습기이다.

온·습도 센서를 이용하여 주변 환경의 온도 및 습도를 측정하고,
측정된 습도와 설정된 동작 조건에 따라 펠티어 소자와 팬을 제어한다.

응축된 수분은 물탱크에 저장하며,
수위 감지를 통해 만수 상태에서는 제습 동작을 정지한다.

### 1.3 시스템 구성

본 시스템은 제어부, 센서부, 제습부, 전원부 및 배수부로 구성한다.

각 구성요소는 제어부를 중심으로 동작하며,
센서부에서 측정한 환경 정보를 기반으로 제습부 및 냉각/방열부를 제어한다.

#### 시스템 구성도

![시스템 구성도](./images/system_configuration.png)

#### 구성요소

| 구성 | 설명 |
|---|---|
| 전원부 | 시스템 각 구성요소에 필요한 전원을 공급한다. |
| 제어부 | 센서 데이터를 수집하고 제습기의 동작을 제어한다. |
| 센서부 | 주변 습도 및 제습부의 온도를 측정한다. |
| 제습부 | 펠티어 소자를 이용하여 공기 중의 수분을 응축한다. |
| 배수부 | 제습 과정에서 발생한 응축수를 수집 및 저장한다. |

### 1.4 기본 동작

본 시스템은 주변 습도를 측정하고 설정된 습도 조건에 따라 제습 동작을 제어한다.

기본 동작은 다음과 같다.

1. 시스템에 전원이 공급되면 제어부 및 각 센서를 초기화한다.
2. 습도 센서를 통해 주변 습도를 측정한다.
3. 측정된 습도가 제습 시작 조건을 만족하면 제습 동작을 시작한다.
4. 제습 동작이 시작되면 펠티어 소자 및 팬을 동작시킨다.
5. 펠티어 소자의 냉각면에서 공기 중의 수분을 응축시킨다.
6. 발생한 응축수는 배수부를 통해 물탱크에 저장한다.
7. 제습 동작 중 주변 습도 및 제습부의 온도를 주기적으로 측정한다.
8. 목표 습도에 도달하면 제습 동작을 정지한다.
9. 과열 또는 결빙 등의 이상 조건이 감지될 경우 제습 동작을 정지한다.
10. 시스템은 다시 주변 습도를 측정하고 제습 필요 여부를 판단한다.

### 2.2 FUNC-001 운전 제어

사용자의 조작에 따라 제습기의 운전 시작 및 정지를 제어한다.

시스템에 전원이 공급되는 동안 제어부, 습도 측정 및 통신 기능은 동작하며, 운전 상태는 제습 기능의 활성화 여부를 나타낸다.

#### 2.2.1 운전 상태

제습기의 운전 상태는 다음과 같이 구분한다.

| 운전 상태 | 설명 |
|---|---|
| OFF | 제습 기능이 비활성화된 대기 상태 |
| ON | 설정된 목표 습도에 따라 자동 제습이 가능한 상태 |

- 시스템 초기화 완료 후 운전 상태의 초기값은 OFF로 한다.
- 운전 상태와 실제 펠티어 소자의 동작 상태는 별도로 관리한다.
- 운전 OFF 상태에서도 습도 측정 및 외부 통신에 필요한 기능은 유지한다.

#### 2.2.2 본체 운전 제어

본체의 운전 터치 버튼을 터치할 때마다 운전 상태를 전환한다.

`OFF → ON → OFF`

- OFF 상태에서 운전 터치 버튼을 입력하면 운전 상태를 ON으로 전환한다.
- 운전 ON 시 저장되어 있는 목표 습도를 기준으로 자동 제습 제어를 시작한다.
- ON 상태에서 운전 터치 버튼을 입력하면 운전 상태를 OFF로 전환한다.
- 운전 OFF 전환 시 동작 중인 펠티어 소자 및 제습에 필요한 구동부를 정지한다.
- 운전 OFF 상태에서도 현재 습도 측정 및 외부 통신 기능은 유지한다.

#### 2.2.3 운전 상태와 제습 동작

운전 상태가 ON이라고 해서 펠티어 소자가 항상 동작하는 것은 아니다.

운전 ON 상태에서 현재 습도와 목표 습도 및 보호 상태를 확인하여 실제 제습 동작 여부를 결정한다.

| 운전 상태 | 제습 조건 | 보호 상태 | 제습 동작 |
|---|---|---|---|
| OFF | - | - | 정지 |
| ON | 미충족 | 정상 | 정지 |
| ON | 충족 | 정상 | 동작 |
| ON | - | 만수 또는 이상 | 정지 |

보호 조건이 발생한 경우 운전 상태와 관계없이 제습 동작을 정지한다.

#### 2.2.4 전원 재인가

- 시스템의 전원이 차단된 후 다시 인가된 경우 운전 상태는 OFF로 초기화한다.
- 이전 운전 ON/OFF 상태는 저장 및 복원하지 않는다.
- 저장된 목표 습도 및 Wi-Fi 설정 정보는 시스템 초기화 시 복원한다.


### 2.3 FUNC-002 습도 측정

주변 공기의 상대습도를 주기적으로 측정하여 현재 습도값으로 관리한다.

습도 측정은 운전 상태와 관계없이 시스템에 전원이 공급되는 동안 수행하며, 측정된 값은 자동 제습 제어, 습도 표시 및 외부 시스템으로의 상태 정보 송신에 사용한다.

#### 2.3.1 습도 측정

- 시스템 초기화가 완료되면 습도 측정을 시작한다.
- 운전 ON/OFF 상태와 관계없이 주변 공기의 습도를 주기적으로 측정한다.
- 측정된 습도는 상대습도(%RH) 단위로 관리한다.
- 정상적으로 취득된 최신 측정값을 현재 습도값으로 관리한다.
- 습도 측정 주기는 별도 제어 사양에서 정의한다.

#### 2.3.2 측정값 사용

측정된 현재 습도값은 다음 기능에서 사용한다.

| 사용 기능 | 용도 |
|---|---|
| 습도 표시 | 본체의 2자리 7-Segment에 현재 습도를 표시한다. |
| 자동 제습 제어 | 운전 ON 상태에서 현재 습도와 목표 습도를 비교하여 제습 동작 여부를 판단한다. |
| 상태 정보 송신 | 현재 습도값을 외부 시스템으로 송신한다. |

#### 2.3.3 측정 이상

- 습도 센서로부터 정상적인 측정값을 취득하지 못한 경우 해당 측정값을 유효한 현재 습도값으로 사용하지 않는다.
- 측정 이상 발생 시 이전 정상 측정값과 현재 측정 상태를 구분하여 관리한다.
- 센서 이상으로 판단된 경우 해당 습도값을 자동 제습 제어에 사용하지 않는다.
- 운전 중 습도 센서 이상이 발생한 경우 제습 동작을 정지한다.
- 센서 이상 판단 조건 및 보호 동작에 대한 상세 내용은 `FUNC-013 센서 이상 감지`에서 정의한다.


### 2.4 FUNC-003 목표 습도 설정

자동 제습 제어에 사용되는 목표 습도를 설정한다.

목표 습도는 본체의 습도 설정 터치 버튼 또는 외부 시스템의 원격 명령을 통해 변경할 수 있으며, 최종 설정값은 비휘발성 메모리에 저장한다.

#### 2.4.1 본체 목표 습도 설정

- 운전 ON 상태에서 습도 설정 터치 버튼을 터치하여 목표 습도를 변경한다.
- 습도 설정 터치 버튼을 한 번 터치할 때마다 목표 습도를 5% 단위로 증가시킨다.
- 목표 습도가 설정 가능한 최댓값에 도달한 상태에서 다시 터치하면 최솟값으로 전환한다.
- 변경된 목표 습도는 자동 제습 제어에 즉시 반영한다.
- 운전 OFF 상태에서는 본체 습도 설정 터치 입력을 통한 목표 습도 변경을 수행하지 않는다.

#### 2.4.2 설정 습도 표시

- 목표 습도 변경 시 2자리 7-Segment에 변경된 목표 습도를 표시한다.
- 목표 습도 표시 중 추가 터치가 입력되면 변경된 목표 습도를 즉시 갱신하여 표시한다.
- 마지막 습도 설정 입력 후 일정 시간이 경과하면 현재 습도 표시로 복귀한다.
- 현재 습도와 목표 습도는 상대습도(%RH) 단위로 관리한다.

#### 2.4.3 원격 목표 습도 설정

- 외부 시스템으로부터 목표 습도 변경 명령을 수신할 수 있다.
- 원격으로 변경된 목표 습도는 본체에서 설정한 목표 습도와 동일한 설정값으로 관리한다.
- 원격으로 목표 습도가 변경된 경우 변경값을 자동 제습 제어에 반영한다.
- 운전 OFF 상태에서 원격으로 목표 습도가 변경된 경우 설정값을 변경 및 저장하되 제습 동작은 시작하지 않는다.
- 이후 운전 상태가 ON으로 전환되면 변경된 목표 습도를 기준으로 자동 제습 제어를 수행한다.
- 원격 설정에 대한 상세 동작은 `FUNC-018 원격 습도 설정`에서 정의한다.

#### 2.4.4 설정값 확정 및 저장

- 목표 습도 변경 시 변경된 값을 자동 제습 제어에 즉시 반영한다.
- 본체에서 목표 습도를 연속적으로 변경하는 경우 마지막 입력 이후 일정 시간 동안 추가 입력이 없으면 해당 값을 최종 설정값으로 확정한다.
- 최종 확정된 목표 습도는 비휘발성 메모리에 저장한다.
- 연속적인 목표 습도 변경이 발생하는 경우 중간 설정값을 반복하여 저장하지 않고 마지막 설정값을 저장한다.
- 시스템 초기화 시 마지막으로 저장된 목표 습도를 복원한다.
- 저장된 목표 습도가 없거나 유효하지 않은 경우 기본 목표 습도값을 적용한다.
- 비휘발성 메모리의 불필요한 쓰기 횟수를 줄이도록 설정값 저장을 제어한다.

### 2.5 FUNC-004 습도 표시

2자리 7-Segment를 이용하여 현재 습도 및 목표 습도를 표시한다.

시스템에 전원이 공급되고 초기화가 완료되면 운전 ON/OFF 상태와 관계없이 현재 습도를 표시한다. 목표 습도 변경 시에는 설정된 목표 습도를 일시적으로 표시하고, 설정이 완료되면 현재 습도 표시로 복귀한다.

#### 2.5.1 현재 습도 표시

- 시스템 초기화가 완료되면 현재 습도를 2자리 7-Segment에 표시한다.
- 운전 ON/OFF 상태와 관계없이 현재 습도를 표시한다.
- 습도 센서에서 새로운 정상 측정값을 취득하면 표시값을 갱신한다.
- 현재 습도는 상대습도(%RH)의 정수값으로 표시한다.
- 시스템에 전원이 공급되는 동안 현재 습도 표시를 유지한다.

#### 2.5.2 목표 습도 표시

- 운전 ON 상태에서 습도 설정 터치 버튼이 입력되면 현재 습도 표시를 일시적으로 중단하고 변경된 목표 습도를 표시한다.
- 습도 설정 터치 버튼을 추가로 입력하면 변경된 목표 습도를 즉시 갱신하여 표시한다.
- 마지막 습도 설정 입력 후 일정 시간이 경과하면 현재 습도 표시로 복귀한다.
- 원격으로 목표 습도가 변경된 경우에도 변경된 목표 습도를 일시적으로 표시한다.

#### 2.5.3 표시 우선순위

현재 습도와 목표 습도 표시 조건이 동시에 발생한 경우 목표 습도 표시를 우선한다.

`목표 습도 > 현재 습도`

목표 습도 표시가 종료되면 최신 현재 습도값을 표시한다.

#### 2.5.4 습도 측정 이상 표시

- 정상적인 현재 습도값을 취득할 수 없는 경우 유효하지 않은 측정값을 표시하지 않는다.
- 습도 센서 이상이 확인된 경우 7-Segment에 측정 이상 상태를 표시한다.
- 센서 이상 발생 시 RGB LED를 RED로 표시한다.
- 7-Segment의 구체적인 이상 표시 방식은 표시 사양에서 정의한다.

### 2.6 FUNC-005 자동 제습 제어

운전 ON 상태에서 현재 습도와 목표 습도를 비교하여 제습 필요 여부를 자동으로 판단한다.

자동 제습 제어는 습도 조건과 시스템의 보호 상태를 기반으로 수행하며, 제습이 필요한 경우 펠티어 및 팬 제어 기능에 동작을 요청한다.

#### 2.6.1 자동 제습 제어 조건

- 운전 상태가 ON인 경우 자동 제습 제어를 수행한다.
- 운전 상태가 OFF인 경우 자동 제습 제어를 수행하지 않는다.
- 현재 습도와 목표 습도를 비교하여 제습 시작 및 종료 여부를 판단한다.
- 정상적인 습도값을 취득할 수 없는 경우 제습 동작을 수행하지 않는다.
- 만수 또는 이상 상태가 발생한 경우 습도 조건과 관계없이 제습 동작을 정지한다.

#### 2.6.2 제습 시작

다음 조건을 모두 만족하는 경우 제습 동작을 시작한다.

- 운전 상태가 ON일 것
- 현재 습도값이 정상적으로 측정되고 있을 것
- 현재 습도가 제습 시작 조건을 만족할 것
- 만수 상태가 아닐 것
- 시스템 이상 또는 보호 조건이 발생하지 않았을 것

제습 시작이 결정되면 펠티어 및 팬 제어 기능에 동작을 요청한다.

#### 2.6.3 제습 종료

다음 조건 중 하나 이상을 만족하는 경우 제습 동작을 정지한다.

- 운전 상태가 OFF로 변경된 경우
- 현재 습도가 제습 종료 조건을 만족한 경우
- 물탱크의 만수 상태가 감지된 경우
- 결빙 또는 과열 보호 조건이 발생한 경우
- 제습 제어에 필요한 센서 이상이 발생한 경우

#### 2.6.4 습도 제어 범위

목표 습도 부근에서 제습 동작이 반복적으로 ON/OFF 되는 것을 방지하기 위해 제습 시작 조건과 종료 조건에 차이를 둔다.

예를 들어 목표 습도가 55%RH인 경우 다음과 같이 제어할 수 있다.

| 현재 상태 | 현재 습도 | 제어 |
|---|---:|---|
| 제습 정지 | 제습 시작 기준 이상 | 제습 시작 |
| 제습 중 | 목표 습도 초과 | 제습 유지 |
| 제습 중 | 목표 습도 도달 이하 | 제습 정지 |
| 제습 정지 | 목표 습도 부근 | 정지 유지 |

제습 시작 기준과 목표 습도 사이의 구체적인 차이값은 실제 제습 성능 및 센서 측정 특성을 확인한 후 제어 사양에서 정의한다.

#### 2.6.5 목표 습도 변경

- 제습 운전 중 목표 습도가 변경된 경우 변경된 목표 습도를 즉시 자동 제습 제어에 반영한다.
- 변경된 목표 습도를 기준으로 현재 습도와 다시 비교하여 제습 동작의 유지, 시작 또는 정지를 판단한다.
- 본체 및 원격 제어를 통한 목표 습도 변경은 동일한 제어 기준을 적용한다.

#### 2.6.6 보호 기능 우선순위

자동 제습 제어보다 시스템 보호 기능을 우선하여 처리한다.

습도 조건이 제습 시작 조건을 만족하더라도 만수, 결빙, 과열 또는 센서 이상 등의 보호 조건이 발생한 경우 제습 동작을 수행하지 않는다.

### 2.7 FUNC-006 펠티어 제어

자동 제습 제어의 판단 결과에 따라 펠티어 소자의 동작을 제어한다.

펠티어 소자는 제습이 필요한 경우 동작하며, 제습 종료 조건 또는 보호 조건이 발생한 경우 동작을 정지한다.

펠티어 소자의 과열을 방지하기 위해 방열 팬의 동작과 연계하여 제어한다.

#### 2.7.1 펠티어 동작

- 자동 제습 제어에서 제습 시작이 결정되면 펠티어 소자를 동작시킨다.
- 펠티어 소자를 동작시키기 전에 방열 팬을 먼저 동작시킨다.
- 방열이 가능한 상태임을 확인한 후 펠티어 소자를 동작시킨다.
- 펠티어 소자의 냉각면을 이용하여 유입된 공기 중의 수분을 응축시킨다.
- 펠티어 소자가 동작하는 동안 방열 팬의 동작을 유지한다.
- 자동 제습 제어에서 제습 정지가 결정되면 펠티어 소자의 동작을 정지한다.
- 운전 OFF 상태에서는 펠티어 소자를 동작시키지 않는다.

#### 2.7.2 펠티어 동작 조건

펠티어 소자는 다음 조건을 모두 만족하는 경우에만 동작한다.

| 조건 | 상태 |
|---|---|
| 운전 상태 | ON |
| 자동 제습 판단 | 제습 필요 |
| 습도 센서 | 정상 |
| 냉각부 온도 | 정상 |
| 방열부 온도 | 정상 |
| 방열 기능 | 정상 |
| 물탱크 | 만수 아님 |
| 시스템 이상 | 없음 |

조건 중 하나라도 만족하지 않는 경우 펠티어 소자의 동작을 시작하지 않거나, 동작 중인 펠티어 소자를 정지한다.

#### 2.7.3 펠티어 정지

다음 조건 중 하나 이상이 발생한 경우 펠티어 소자의 동작을 정지한다.

- 자동 제습 제어에서 제습 종료가 결정된 경우
- 운전 상태가 OFF로 변경된 경우
- 물탱크의 만수 상태가 감지된 경우
- 냉각부의 결빙 보호 조건이 발생한 경우
- 방열부의 과열 보호 조건이 발생한 경우
- 제습 제어에 필요한 센서 이상이 발생한 경우
- 방열 기능에 이상이 발생한 경우
- 기타 시스템 보호 조건이 발생한 경우

펠티어 소자가 정지한 이후의 방열 팬 동작은 `FUNC-007 팬 제어`에 따라 수행한다.

#### 2.7.4 보호 상태에서의 재동작

- 보호 조건으로 인해 펠티어 소자가 정지한 경우 보호 조건이 해제될 때까지 펠티어 소자를 재동작시키지 않는다.
- 보호 조건이 해제된 후 운전 상태, 제습 조건, 센서 상태 및 방열 상태를 다시 확인한다.
- 모든 재동작 조건을 만족하는 경우 자동 제습 제어의 판단에 따라 펠티어 소자를 다시 동작시킨다.

#### 2.7.5 초기 상태

- 시스템 전원 인가 시 펠티어 소자의 초기 상태는 OFF로 한다.
- 시스템 초기화가 완료되기 전에는 펠티어 소자를 동작시키지 않는다.
- 운전 상태, 센서 상태 및 보호 상태를 확인한 후 자동 제습 제어에 따라 펠티어 소자의 동작 여부를 결정한다.

### 2.8 FUNC-007 팬 제어

제습에 필요한 공기 순환 및 펠티어 소자의 방열을 위해 흡기 팬과 방열 팬을 제어한다.

흡기 팬과 방열 팬은 각각 독립적으로 제어하며, 제습 상태 및 보호 상태에 따라 동작 여부를 결정한다.

#### 2.8.1 팬 구성

| 구분 | 역할 |
|---|---|
| 흡기 팬 | 외부 공기를 제습부로 유입시켜 냉각부와 공기가 접촉할 수 있도록 한다. |
| 방열 팬 | 펠티어 소자의 방열부와 접촉된 공랭 쿨러를 냉각하여 펠티어에서 발생하는 열을 외부로 방출한다. |

#### 2.8.2 흡기 팬 제어

- 제습 동작이 시작되면 흡기 팬을 동작시킨다.
- 흡기 팬을 통해 외부 공기를 제습부로 유입시킨다.
- 유입된 공기가 펠티어 냉각부와 열교환할 수 있도록 공기 흐름을 유지한다.
- 제습 동작이 종료되면 흡기 팬을 정지한다.
- 운전 OFF 상태에서는 흡기 팬을 동작시키지 않는다.
- 만수, 결빙, 과열 또는 시스템 이상으로 제습이 중단된 경우 흡기 팬을 정지한다.

#### 2.8.3 방열 팬 제어

- 펠티어 소자가 동작하기 전에 방열 팬을 먼저 동작시킨다.
- 펠티어 소자가 동작하는 동안 방열 팬의 동작을 유지한다.
- 방열 팬을 이용하여 공랭 쿨러의 히트싱크에서 발생하는 열을 외부로 방출한다.
- 펠티어 소자가 정지한 경우에도 잔열 제거를 위해 일정 시간 동안 방열 팬의 동작을 유지한다.
- 후속 방열 시간은 실제 방열 성능을 확인한 후 별도 제어 사양에서 정의한다.

#### 2.8.4 과열 발생 시 제어

- 방열부의 온도가 과열 보호 조건을 만족하면 펠티어 소자를 즉시 정지한다.
- 과열 상태에서는 흡기 팬을 정지한다.
- 방열 팬은 과열 상태가 해제될 때까지 동작을 유지한다.
- 방열부 온도가 정상 범위로 복귀한 후 자동 제습 조건을 다시 확인한다.
- 재동작 조건을 만족하는 경우 제습 동작을 재개한다.

#### 2.8.5 보호 상태에 따른 팬 동작

| 상태 | 펠티어 | 흡기 팬 | 방열 팬 |
|---|---|---|---|
| 제습 중 | ON | ON | ON |
| 목표 습도 도달 | OFF | OFF | 후속 방열 후 OFF |
| 운전 OFF | OFF | OFF | 후속 방열 후 OFF |
| 만수 | OFF | OFF | 후속 방열 후 OFF |
| 결빙 | OFF | OFF | 후속 방열 후 OFF |
| 과열 | OFF | OFF | ON |
| 센서 이상 | OFF | OFF | 후속 방열 후 OFF |

#### 2.8.6 초기 상태

- 시스템 전원 인가 시 흡기 팬 및 방열 팬의 초기 상태는 OFF로 한다.
- 시스템 초기화가 완료되기 전에는 각 팬을 동작시키지 않는다.
- 자동 제습 시작 시 방열 팬의 정상 동작 상태를 확보한 후 펠티어 및 흡기 팬을 동작시킨다.

### 2.9 FUNC-008 온도 감시

펠티어 소자의 냉각부 및 방열부 온도를 측정하여 제습 시스템의 온도 상태를 감시한다.

냉각부와 방열부에 각각 온도 센서를 배치하며, 측정된 온도값은 결빙 보호 및 과열 보호 기능의 판단 정보로 사용한다.

#### 2.9.1 온도 감시 대상

온도 감시 대상은 다음과 같다.

| 감시 대상 | 설치 위치 | 용도 |
|---|---|---|
| 냉각부 온도 | 펠티어 냉각면 또는 냉각부 | 결빙 가능성 감시 |
| 방열부 온도 | 펠티어 방열면 또는 방열부와 접촉하는 히트싱크 | 과열 상태 감시 |

온도 센서의 구체적인 종류 및 설치 위치는 하드웨어 설계에서 정의한다.

#### 2.9.2 온도 측정

- 시스템 초기화가 완료되면 냉각부 및 방열부의 온도 측정을 시작한다.
- 시스템에 전원이 공급되는 동안 각 온도를 주기적으로 측정한다.
- 측정된 온도는 섭씨(°C) 단위로 관리한다.
- 정상적으로 취득된 최신 측정값을 각 부위의 현재 온도값으로 관리한다.
- 온도 측정 주기는 별도 제어 사양에서 정의한다.

#### 2.9.3 냉각부 온도 감시

- 냉각부 온도를 주기적으로 감시한다.
- 측정된 냉각부 온도는 결빙 가능성을 판단하는 데 사용한다.
- 냉각부 온도가 결빙 보호 조건을 만족하는 경우 `FUNC-010 결빙 보호`를 수행한다.
- 결빙 보호 상태에서도 냉각부 온도 측정을 계속하여 보호 해제 조건을 확인한다.

#### 2.9.4 방열부 온도 감시

- 방열부 온도를 주기적으로 감시한다.
- 측정된 방열부 온도는 펠티어 소자의 과열 가능성을 판단하는 데 사용한다.
- 방열부 온도가 과열 보호 조건을 만족하는 경우 `FUNC-011 과열 보호`를 수행한다.
- 과열 보호 상태에서도 방열부 온도 측정을 계속하여 보호 해제 조건을 확인한다.

#### 2.9.5 측정값 사용

측정된 온도값은 다음 기능에서 사용한다.

| 측정값 | 사용 기능 | 용도 |
|---|---|---|
| 냉각부 온도 | `FUNC-010 결빙 보호` | 결빙 보호 시작 및 해제 판단 |
| 방열부 온도 | `FUNC-011 과열 보호` | 과열 보호 시작 및 해제 판단 |
| 방열부 온도 | `FUNC-007 팬 제어` | 과열 발생 시 방열 팬 제어 판단 |

#### 2.9.6 온도 측정 이상

- 온도 센서로부터 정상적인 측정값을 취득하지 못한 경우 해당 측정값을 유효한 온도값으로 사용하지 않는다.
- 측정 이상 발생 시 이전 정상 측정값과 현재 측정 상태를 구분하여 관리한다.
- 냉각부 또는 방열부 온도를 정상적으로 확인할 수 없는 경우 안전을 위해 펠티어 소자를 동작시키지 않는다.
- 펠티어 소자 동작 중 온도 센서 이상이 발생한 경우 제습 동작을 중지한다.
- 온도 센서의 이상 판단 및 복구 조건은 `FUNC-013 센서 이상 감지`에서 정의한다.

### 2.10 FUNC-009 만수 감지 및 보호

물탱크의 수위를 감지하여 만수 상태를 판단하고, 물이 넘치는 것을 방지하기 위해 제습 동작을 제어한다.

만수 상태가 감지된 경우 제습 동작을 중지하고 만수 상태 표시를 통해 사용자에게 물탱크의 물을 제거해야 함을 알린다.

#### 2.10.1 만수 감지

- 물탱크에 수위 감지 센서를 설치하여 만수 여부를 감지한다.
- 시스템에 전원이 공급되는 동안 물탱크의 수위 상태를 주기적으로 감시한다.
- 수위가 만수 기준에 도달한 경우 만수 상태로 판단한다.
- 만수 감지 방식 및 세부 판정 조건은 하드웨어 및 제어 사양에서 정의한다.

#### 2.10.2 만수 발생 시 제어

만수 상태가 감지된 경우 다음과 같이 제어한다.

- 운전 상태는 ON으로 유지한다.
- 펠티어 소자를 즉시 정지한다.
- 흡기 팬을 정지한다.
- 방열 팬은 펠티어 소자의 잔열 제거를 위해 일정 시간 동안 동작한 후 정지한다.
- 만수 상태가 유지되는 동안 제습 동작을 수행하지 않는다.
- 제습 상태 표시 LED를 점멸한다.
- 만수 상태 표시 LED를 점등한다.
- 현재 습도 측정 및 외부 시스템과의 통신은 계속 수행한다.
- 외부 시스템으로 만수 상태 정보를 송신한다.

#### 2.10.3 만수 상태 해제

- 사용자가 물탱크의 물을 제거하여 수위가 만수 기준 이하로 내려간 경우 만수 상태를 해제한다.
- 만수 상태 표시 LED를 소등한다.
- 다른 보호 또는 이상 상태의 발생 여부를 확인한다.
- 다른 보호 상태가 존재하는 경우 제습 상태 표시 LED의 점멸을 유지하고 제습 동작을 재개하지 않는다.
- 운전 상태가 ON이고 다른 보호 상태가 없으며 제습 조건을 만족하는 경우 자동으로 제습 동작을 재개한다.
- 제습 동작이 재개되면 제습 상태 표시 LED를 점멸 상태에서 점등 상태로 변경한다.
- 제습 조건을 만족하지 않는 경우 제습 상태 표시 LED를 소등하고 대기한다.
- 만수 상태 중 사용자가 운전을 OFF로 변경한 경우 만수 상태가 해제되더라도 제습 동작을 재개하지 않는다.

#### 2.10.4 복수 상태 표시

만수 상태와 다른 이상 상태가 동시에 발생한 경우 각 상태를 독립적으로 표시한다.

예를 들어 만수 상태와 시스템 이상이 동시에 발생한 경우 만수 표시와 이상 표시를 모두 점등한다.

- 만수 상태 표시와 이상 상태 표시는 서로 독립적으로 제어한다.
- 만수 상태가 해제되면 만수 표시만 소등한다.
- 다른 이상 상태가 지속되고 있는 경우 이상 상태 표시는 유지한다.
- 각 상태 표시와 관계없이 발생한 보호 기능은 독립적으로 수행한다.

#### 2.10.5 초기 상태

- 시스템 초기화 시 물탱크의 만수 여부를 확인한다.
- 초기화 시 이미 만수 상태인 경우 제습 동작을 허용하지 않는다.
- 만수 상태가 확인된 경우 만수 상태 표시 LED를 점등한다.
- 만수 상태가 해제된 후 운전 상태 및 다른 보호 조건을 확인하여 제습 가능 여부를 판단한다.

### 2.11 FUNC-010 결빙 보호

펠티어 냉각부의 온도를 감시하여 냉각부의 결빙을 방지한다.

냉각부 온도가 결빙 보호 조건을 만족하는 경우 운전 상태는 유지한 채 제습 동작을 일시적으로 중지한다.

냉각부 온도가 정상 범위로 회복되면 결빙 보호 상태를 해제하고, 운전 상태 및 제습 조건을 확인하여 자동으로 제습 동작을 재개한다.

#### 2.11.1 결빙 감지

- 냉각부 온도 센서의 측정값을 이용하여 결빙 가능성을 감시한다.
- 펠티어 소자가 동작하는 동안 냉각부 온도를 주기적으로 확인한다.
- 냉각부 온도가 설정된 결빙 보호 기준 이하로 내려간 경우 결빙 보호 상태로 전환한다.
- 결빙 보호 기준 온도 및 세부 판정 조건은 실제 냉각 성능을 확인한 후 별도 제어 사양에서 정의한다.

#### 2.11.2 결빙 보호 동작

결빙 보호 상태가 발생한 경우 다음과 같이 제어한다.

- 운전 상태는 ON으로 유지한다.
- 펠티어 소자를 즉시 정지한다.
- 흡기 팬을 정지한다.
- 방열 팬은 펠티어 소자의 잔열 제거를 위해 일정 시간 동안 동작한 후 정지한다.
- 결빙 보호 상태가 유지되는 동안 제습 동작을 수행하지 않는다.
- 제습 상태 표시 LED를 점멸한다.
- 에러 상태 표시 LED를 점등한다.
- 현재 습도 및 냉각부 온도 측정을 계속 수행한다.
- 외부 시스템과의 통신을 유지하고 결빙 보호 상태 정보를 송신한다.

#### 2.11.3 결빙 보호 해제

- 결빙 보호 상태에서도 냉각부 온도를 지속적으로 감시한다.
- 냉각부 온도가 설정된 결빙 보호 해제 기준 이상으로 회복된 경우 결빙 보호 상태를 해제한다.
- 결빙 보호 해제 후 다른 보호 또는 이상 상태의 발생 여부를 확인한다.
- 다른 이상 상태가 존재하지 않는 경우 에러 상태 표시 LED를 소등한다.
- 다른 보호 상태가 존재하는 경우 제습 동작을 재개하지 않는다.
- 운전 상태가 ON이고 다른 보호 상태가 없으며 제습 조건을 만족하는 경우 자동으로 제습 동작을 재개한다.
- 제습 동작이 재개되면 제습 상태 표시 LED를 점멸 상태에서 점등 상태로 변경한다.
- 제습 조건을 만족하지 않는 경우 제습 상태 표시 LED를 소등하고 대기한다.
- 결빙 보호 중 사용자가 운전을 OFF로 변경한 경우 보호 상태가 해제되더라도 제습 동작을 재개하지 않는다.

#### 2.11.4 결빙 보호 제어 범위

결빙 보호 상태가 짧은 시간 동안 반복적으로 발생 및 해제되는 것을 방지하기 위해 결빙 보호 진입 기준과 해제 기준에 차이를 둔다.

| 냉각부 온도 조건 | 제어 |
|---|---|
| 결빙 보호 기준 이하 | 결빙 보호 시작 |
| 결빙 보호 기준 초과 ~ 해제 기준 미만 | 결빙 보호 상태 유지 |
| 결빙 보호 해제 기준 이상 | 결빙 보호 해제 |

결빙 보호 기준 및 해제 기준의 구체적인 온도는 실제 펠티어 소자와 냉각부의 동작 특성을 확인한 후 결정한다.

#### 2.11.5 상태 표시

결빙 보호 발생 시 상태 표시는 다음과 같이 제어한다.

| 상태 | 제습 LED | 만수 LED | 에러 LED |
|---|---|---|---|
| 정상 제습 중 | 점등 | OFF | OFF |
| 결빙 보호 중 | 점멸 | OFF | 점등 |
| 결빙 해제 후 제습 재개 | 점등 | OFF | OFF |
| 결빙 해제 후 제습 대기 | OFF | OFF | OFF |

결빙과 다른 보호 상태가 동시에 발생한 경우 각 상태를 독립적으로 관리하며, 모든 제습 제한 조건이 해제되기 전까지 제습 동작을 재개하지 않는다.

### 2.13 FUNC-012 상태 표시

본체의 상태 표시 LED를 이용하여 제습 동작, 만수, 시스템 이상 및 Wi-Fi 연결 상태를 사용자에게 표시한다.

상태 표시는 제습 상태 표시, 만수 상태 표시, 에러 상태 표시 및 Wi-Fi 상태 표시로 구성하며 각각 독립적으로 제어한다.

#### 2.13.1 상태 표시 구성

| 표시 항목 | 표시 방식 | 설명 |
|---|---|---|
| 제습 상태 | 제습 LED | 현재 제습 동작 및 보호에 의한 일시 정지 상태를 표시한다. |
| 만수 상태 | 만수 LED | 물탱크의 만수 상태를 표시한다. |
| 에러 상태 | 에러 LED | 결빙, 과열 및 센서 이상 등의 시스템 이상 상태를 표시한다. |
| Wi-Fi 상태 | Wi-Fi RGB LED | Wi-Fi 네트워크의 연결 상태를 색상으로 표시한다. |

#### 2.13.2 제습 상태 표시

제습 상태 LED는 운전 및 실제 제습 상태에 따라 다음과 같이 제어한다.

| 상태 | 제습 LED |
|---|---|
| 운전 OFF | 소등 |
| 운전 ON / 제습 대기 | 소등 |
| 정상 제습 중 | 점등 |
| 보호 상태에 의한 제습 일시 정지 | 점멸 |

- 실제 펠티어 소자가 정상적으로 동작하여 제습을 수행하는 동안 제습 LED를 점등한다.
- 목표 습도 도달 등 정상적인 조건에 의해 제습이 정지된 경우 제습 LED를 소등한다.
- 운전 ON 상태에서 만수 또는 시스템 이상 등의 보호 조건으로 제습이 일시 중지된 경우 제습 LED를 점멸한다.
- 보호 상태가 해제되어 제습이 재개되면 제습 LED를 점등 상태로 변경한다.
- 보호 상태가 해제되었으나 제습 조건을 만족하지 않는 경우 제습 LED를 소등한다.

#### 2.13.3 만수 상태 표시

- 물탱크의 만수 상태가 감지되면 만수 LED를 점등한다.
- 만수 상태가 유지되는 동안 만수 LED의 점등 상태를 유지한다.
- 사용자가 물탱크의 물을 제거하여 만수 상태가 해제되면 만수 LED를 소등한다.
- 만수 상태는 시스템의 다른 이상 상태와 독립적으로 표시한다.

#### 2.13.4 에러 상태 표시

- 시스템 이상 또는 보호 조건이 감지된 경우 에러 LED를 점등한다.
- 결빙, 과열 및 센서 이상 등의 상태를 에러 상태로 관리한다.
- 하나 이상의 에러 상태가 존재하는 동안 에러 LED의 점등 상태를 유지한다.
- 모든 에러 상태가 해제된 경우 에러 LED를 소등한다.
- 에러 상태의 세부 종류는 내부 상태 정보 및 외부 시스템으로 송신되는 상태 정보를 통해 구분한다.
- Wi-Fi 미접속 또는 연결 실패 상태는 시스템 에러 상태에 포함하지 않는다.

#### 2.13.5 Wi-Fi 상태 표시

Wi-Fi 연결 상태는 Wi-Fi 상태 표시용 RGB LED를 이용하여 표시한다.

| Wi-Fi 상태 | RGB LED | 설명 |
|---|---|---|
| 미접속 | RED | Wi-Fi 네트워크에 연결되어 있지 않은 상태 |
| 연결 시도 중 | BLUE | 설정된 Wi-Fi 네트워크에 연결을 시도하고 있는 상태 |
| 연결 완료 | GREEN | Wi-Fi 네트워크에 정상적으로 연결된 상태 |

- Wi-Fi 네트워크에 연결되어 있지 않은 경우 RED로 표시한다.
- 저장된 Wi-Fi 접속 정보를 이용하여 연결을 시도하는 동안 BLUE로 표시한다.
- Wi-Fi 연결에 성공하면 GREEN으로 표시한다.
- Wi-Fi 연결에 실패하거나 연결된 네트워크와의 접속이 끊어진 경우 RED로 표시한다.
- Wi-Fi 재접속을 시도하는 동안 BLUE로 표시한다.
- Wi-Fi 상태 표시는 운전 상태, 제습 상태 및 시스템 에러 상태와 독립적으로 제어한다.
- Wi-Fi 연결 상태가 제습기의 기본 운전 및 보호 기능에 영향을 주지 않도록 한다.

#### 2.13.6 복수 상태 표시

각 상태 표시 LED는 독립적으로 제어하며, 복수의 상태가 동시에 발생한 경우 해당 상태를 동시에 표시한다.

| 시스템 상태 | 제습 LED | 만수 LED | 에러 LED | Wi-Fi RGB LED |
|---|---|---|---|---|
| 운전 OFF | 소등 | 소등 | 소등 | Wi-Fi 상태에 따라 표시 |
| 운전 ON / 제습 대기 | 소등 | 소등 | 소등 | Wi-Fi 상태에 따라 표시 |
| 정상 제습 중 | 점등 | 소등 | 소등 | Wi-Fi 상태에 따라 표시 |
| 만수 보호 중 | 점멸 | 점등 | 소등 | Wi-Fi 상태에 따라 표시 |
| 결빙 보호 중 | 점멸 | 소등 | 점등 | Wi-Fi 상태에 따라 표시 |
| 과열 보호 중 | 점멸 | 소등 | 점등 | Wi-Fi 상태에 따라 표시 |
| 센서 이상 | 점멸 | 소등 | 점등 | Wi-Fi 상태에 따라 표시 |
| 만수 + 시스템 이상 | 점멸 | 점등 | 점등 | Wi-Fi 상태에 따라 표시 |

Wi-Fi 상태는 다른 상태와 독립적으로 표시한다.

#### 2.13.7 초기 상태

- 시스템 전원 인가 시 제습 LED, 만수 LED 및 에러 LED를 소등 상태로 초기화한다.
- 초기화 완료 후 현재 운전 상태, 만수 상태 및 시스템 이상 상태를 확인하여 각 LED의 표시 상태를 갱신한다.
- Wi-Fi RGB LED는 초기 Wi-Fi 연결 상태에 따라 표시한다.
- Wi-Fi 미접속 상태에서는 RED로 표시하고, Wi-Fi 연결을 시작하면 BLUE로 변경한다.
- Wi-Fi 연결이 완료되면 GREEN으로 변경한다.

### 2.14 FUNC-013 센서 이상 감지

시스템에서 사용하는 각 센서의 측정 및 통신 상태를 감시하여 센서 이상 여부를 판단한다.

제습 또는 보호 제어에 필요한 센서에서 이상이 감지된 경우 안전을 위해 제습 동작을 중지하고 사용자 및 외부 시스템에 이상 상태를 알린다.

#### 2.14.1 감시 대상

다음 센서를 이상 감지 대상으로 한다.

| 센서 | 용도 |
|---|---|
| 습도 센서 | 현재 습도 측정 및 자동 제습 제어 |
| 냉각부 온도 센서 | 냉각부 온도 감시 및 결빙 보호 |
| 방열부 온도 센서 | 방열부 온도 감시 및 과열 보호 |
| 수위 센서 | 물탱크 만수 감지 |

#### 2.14.2 센서 이상 판단

다음과 같은 상태가 발생한 경우 센서 이상 여부를 판단한다.

- 센서로부터 정상적인 측정값을 취득할 수 없는 경우
- 센서와의 통신에 실패한 경우
- 측정값이 센서의 정상 측정 범위를 벗어난 경우
- 일정 횟수 이상 연속하여 정상적인 측정값을 취득하지 못한 경우
- 기타 센서의 정상적인 동작을 확인할 수 없는 경우

일시적인 측정 또는 통신 실패를 즉시 센서 이상으로 판단하지 않으며, 연속 실패 횟수 등의 구체적인 판정 기준은 별도 제어 사양에서 정의한다.

#### 2.14.3 센서 이상 발생 시 제어

제습 및 보호 제어에 필요한 센서의 이상이 확인된 경우 다음과 같이 제어한다.

- 운전 상태는 ON으로 유지한다.
- 펠티어 소자를 정지한다.
- 흡기 팬을 정지한다.
- 방열 팬은 펠티어 소자의 잔열 제거가 필요한 경우 일정 시간 동안 동작한 후 정지한다.
- 센서 이상 상태가 유지되는 동안 제습 동작을 수행하지 않는다.
- 운전 ON 상태인 경우 제습 상태 표시 LED를 점멸한다.
- 에러 상태 표시 LED를 점등한다.
- 정상적으로 동작하는 다른 센서의 측정은 계속 수행한다.
- 외부 시스템과의 통신이 가능한 경우 센서 이상 상태 및 이상이 발생한 센서 정보를 송신한다.

#### 2.14.4 센서별 보호 동작

| 이상 센서 | 제습 동작 | 사유 |
|---|---|---|
| 습도 센서 | 정지 | 현재 습도를 정상적으로 판단할 수 없음 |
| 냉각부 온도 센서 | 정지 | 결빙 여부를 정상적으로 판단할 수 없음 |
| 방열부 온도 센서 | 정지 | 과열 여부를 정상적으로 판단할 수 없음 |
| 수위 센서 | 정지 | 물탱크 만수 여부를 정상적으로 판단할 수 없음 |

안전한 제습 동작을 위해 위 센서 중 제습 및 보호 제어에 필요한 센서에서 이상이 확인된 경우 제습 동작을 제한한다.

#### 2.14.5 센서 이상 해제

- 이상이 발생한 센서의 상태를 지속적으로 확인한다.
- 센서로부터 정상적인 측정값이 일정 횟수 이상 연속하여 확인된 경우 센서 이상 상태를 해제한다.
- 다른 센서 또는 시스템 이상이 존재하지 않는 경우 에러 상태 표시 LED를 소등한다.
- 다른 보호 상태가 존재하는 경우 제습 동작을 재개하지 않는다.
- 운전 상태가 ON이고 모든 제습 제한 조건이 해제되었으며 제습 조건을 만족하는 경우 자동으로 제습 동작을 재개한다.
- 제습이 재개되면 제습 상태 표시 LED를 점멸 상태에서 점등 상태로 변경한다.
- 제습 조건을 만족하지 않는 경우 제습 상태 표시 LED를 소등하고 대기한다.

#### 2.14.6 복수 센서 이상

- 두 개 이상의 센서에서 동시에 이상이 발생한 경우 각각의 센서 이상 상태를 독립적으로 관리한다.
- 하나의 센서가 정상 상태로 복구되더라도 다른 센서 이상이 유지되는 경우 에러 상태를 해제하지 않는다.
- 모든 센서 이상이 해제되고 다른 시스템 이상이 존재하지 않는 경우 에러 상태 표시 LED를 소등한다.
- 외부 시스템에는 이상이 발생한 센서를 개별적으로 구분하여 상태 정보를 송신한다.

### 2.15 FUNC-014 Wi-Fi 설정

외부 시스템과의 통신을 위해 제습기가 접속할 Wi-Fi 네트워크 정보를 설정한다.

최초 사용 시 Pico 2 WH의 AP(Access Point) 모드를 이용하여 Wi-Fi 설정용 네트워크를 생성하고, 사용자는 스마트폰 등의 단말기를 통해 제습기에 접속하여 Wi-Fi 정보를 설정한다.

설정된 Wi-Fi 접속 정보는 비휘발성 메모리에 저장하여 전원 재인가 후에도 유지한다.

#### 2.15.1 Wi-Fi 설정 모드

- 시스템 초기화 시 저장된 Wi-Fi 접속 정보의 존재 여부를 확인한다.
- 저장된 Wi-Fi 접속 정보가 없는 경우 Wi-Fi 설정 모드로 진입한다.
- Wi-Fi 설정 모드에서는 Pico 2 WH를 AP 모드로 동작시켜 설정용 Wi-Fi 네트워크를 생성한다.
- 사용자는 스마트폰 등의 Wi-Fi 지원 단말기를 이용하여 설정용 네트워크에 접속한다.
- 설정용 네트워크의 SSID 및 세부 접속 사양은 별도 통신 사양에서 정의한다.
- Wi-Fi 설정 모드에서도 제습기의 기본 제어 및 보호 기능은 독립적으로 동작한다.

#### 2.15.2 Wi-Fi 접속 정보 입력

- 사용자는 설정용 Wi-Fi 네트워크에 접속한 후 웹 인터페이스를 통해 Wi-Fi 접속 정보를 입력한다.
- Wi-Fi 접속을 위해 다음 정보를 입력 및 관리한다.

| 설정 항목 | 설명 |
|---|---|
| SSID | 제습기가 접속할 Wi-Fi 네트워크의 식별 정보 |
| 인증 정보 | Wi-Fi 네트워크 접속에 필요한 비밀번호 등의 인증 정보 |

- 입력된 Wi-Fi 접속 정보는 외부 상태 정보로 송신하지 않는다.
- 저장된 인증 정보가 일반적인 상태 조회 등을 통해 노출되지 않도록 관리한다.

#### 2.15.3 설정값 저장

- 사용자가 Wi-Fi 설정을 완료하면 입력된 접속 정보를 비휘발성 메모리에 저장한다.
- 시스템 전원이 차단되더라도 저장된 Wi-Fi 접속 정보를 유지한다.
- 시스템 초기화 시 저장된 Wi-Fi 접속 정보를 확인한다.
- 유효한 Wi-Fi 접속 정보가 존재하는 경우 해당 정보를 `FUNC-015 Wi-Fi 연결`에서 사용한다.
- Wi-Fi 접속 정보가 정상적으로 저장된 후 Wi-Fi 설정 모드를 종료한다.

#### 2.15.4 Wi-Fi 연결 전환

Wi-Fi 설정이 완료된 경우 다음 순서로 일반 Wi-Fi 연결 상태로 전환한다.

1. 입력된 Wi-Fi 접속 정보를 비휘발성 메모리에 저장한다.
2. Wi-Fi 설정용 AP 모드를 종료한다.
3. Pico 2 WH를 Wi-Fi 클라이언트 모드로 전환한다.
4. 저장된 Wi-Fi 접속 정보를 이용하여 설정된 Wi-Fi 네트워크에 연결을 시도한다.
5. 연결 결과에 따라 Wi-Fi 상태를 갱신한다.

- Wi-Fi 연결을 시도하는 동안 Wi-Fi RGB LED를 BLUE로 표시한다.
- Wi-Fi 연결에 성공하면 Wi-Fi RGB LED를 GREEN으로 표시한다.
- Wi-Fi 연결에 실패하면 Wi-Fi RGB LED를 RED로 표시한다.
- Wi-Fi 연결 및 재접속에 대한 상세 동작은 `FUNC-015 Wi-Fi 연결` 및 `FUNC-015 Wi-Fi 연결`에서 정의한다.

#### 2.15.5 Wi-Fi 설정 초기화

저장된 Wi-Fi 접속 정보를 변경해야 하는 경우 본체의 Wi-Fi RESET 버튼을 이용하여 Wi-Fi 설정을 초기화한다.

- Wi-Fi RESET 버튼은 일반적인 사용자 조작에 의해 잘못 입력되지 않도록 본체 후면 또는 바닥에 배치한다.
- Wi-Fi RESET 버튼을 일정 시간 이상 연속으로 누른 경우 Wi-Fi 설정 초기화를 수행한다.
- 초기화에 필요한 구체적인 입력 시간은 별도 인터페이스 사양에서 정의한다.
- Wi-Fi 설정 초기화 시 비휘발성 메모리에 저장된 기존 Wi-Fi 접속 정보를 삭제한다.
- 현재 Wi-Fi에 연결되어 있는 경우 기존 연결을 종료한다.
- 초기화 완료 후 Wi-Fi 설정 모드로 진입한다.
- 설정용 Wi-Fi 네트워크를 생성하여 새로운 Wi-Fi 접속 정보를 입력할 수 있도록 한다.
- Wi-Fi 설정 초기화는 목표 습도 등의 제습기 설정값에는 영향을 주지 않는다.

#### 2.15.6 Wi-Fi 설정 실패

- Wi-Fi 접속 정보 입력 또는 설정 과정이 정상적으로 완료되지 않은 경우 유효하지 않은 접속 정보를 사용하지 않는다.
- Wi-Fi 네트워크에 접속하지 못한 경우 Wi-Fi RGB LED를 RED로 표시한다.
- Wi-Fi 설정 및 연결 실패는 시스템 에러 상태로 처리하지 않으며 에러 LED를 점등하지 않는다.
- Wi-Fi 설정 또는 연결 실패가 제습기의 기본 제어 및 보호 기능에 영향을 주지 않도록 한다.
- Wi-Fi가 설정되지 않은 상태에서도 습도 측정, 운전 제어, 자동 제습 및 보호 기능은 정상적으로 동작한다.

#### 2.15.7 Wi-Fi 상태 표시

Wi-Fi 설정 및 연결 과정의 상태는 Wi-Fi RGB LED를 통해 표시한다.

| Wi-Fi 상태 | Wi-Fi RGB LED |
|---|---|
| Wi-Fi 미설정 | RED |
| Wi-Fi 설정 모드 | RED |
| Wi-Fi 미접속 | RED |
| Wi-Fi 연결 시도 중 | BLUE |
| Wi-Fi 연결 완료 | GREEN |
| Wi-Fi 연결 실패 | RED |

Wi-Fi RGB LED의 상세 표시 사양은 `FUNC-012 상태 표시`에 따른다.

### 2.16 FUNC-015 Wi-Fi 연결

저장된 Wi-Fi 접속 정보를 이용하여 제습기를 Wi-Fi 네트워크에 연결한다.

시스템 초기화 후 유효한 Wi-Fi 접속 정보가 존재하는 경우 자동으로 연결을 시도하며, 연결 상태는 Wi-Fi RGB LED를 통해 사용자에게 표시한다.

Wi-Fi 연결 여부와 관계없이 제습기의 기본 제어 및 보호 기능은 독립적으로 동작한다.

#### 2.16.1 Wi-Fi 연결 시작

- 시스템 초기화 시 저장된 Wi-Fi 접속 정보의 존재 여부를 확인한다.
- 유효한 Wi-Fi 접속 정보가 존재하는 경우 해당 정보를 이용하여 Wi-Fi 연결을 자동으로 시도한다.
- Wi-Fi 연결은 운전 ON/OFF 상태와 관계없이 수행한다.
- Wi-Fi 연결을 시도하는 동안 Wi-Fi RGB LED를 BLUE로 표시한다.
- 저장된 Wi-Fi 접속 정보가 없는 경우 Wi-Fi 연결을 시도하지 않고 Wi-Fi RGB LED를 RED로 표시한다.
- Wi-Fi 접속 정보가 없는 경우 `FUNC-014 Wi-Fi 설정`을 통해 접속 정보를 설정할 수 있도록 한다.

#### 2.16.2 Wi-Fi 연결 처리

Wi-Fi 연결은 다음 순서로 수행한다.

1. 비휘발성 메모리에 저장된 Wi-Fi 접속 정보를 불러온다.
2. Wi-Fi 통신 기능을 초기화한다.
3. Wi-Fi RGB LED를 BLUE로 변경한다.
4. 설정된 Wi-Fi 네트워크에 연결을 시도한다.
5. 연결 결과를 확인한다.
6. 연결 성공 또는 실패 결과에 따라 Wi-Fi 연결 상태 및 RGB LED를 갱신한다.

Wi-Fi 연결에 필요한 세부 통신 방식 및 접속 처리 방법은 별도 통신 사양에서 정의한다.

#### 2.16.3 연결 성공

Wi-Fi 네트워크에 정상적으로 연결된 경우 다음과 같이 처리한다.

- Wi-Fi 연결 상태를 연결 완료 상태로 변경한다.
- Wi-Fi RGB LED를 GREEN으로 표시한다.
- 외부 시스템과의 통신 기능을 활성화한다.
- 상태 정보 송신 및 원격 제어 기능을 사용할 수 있는 상태로 전환한다.
- Wi-Fi 연결은 운전 상태 및 제습 동작과 독립적으로 유지한다.

#### 2.16.4 연결 실패 및 재시도

Wi-Fi 네트워크에 정상적으로 연결하지 못한 경우 다음과 같이 처리한다.

- Wi-Fi 연결 상태를 미접속 상태로 변경한다.
- Wi-Fi RGB LED를 RED로 표시한다.
- Wi-Fi 연결 실패는 시스템 에러 상태로 처리하지 않으며 에러 LED를 점등하지 않는다.
- 연결 실패 후 5초 동안 대기한 후 저장된 Wi-Fi 접속 정보를 이용하여 자동으로 재접속을 시도한다.
- 재접속을 시작하면 Wi-Fi RGB LED를 BLUE로 변경한다.
- 재접속에 성공하면 Wi-Fi RGB LED를 GREEN으로 변경한다.
- 재접속에 실패한 경우 다시 RED로 변경하고 5초 후 재접속을 반복한다.
- Wi-Fi 연결이 완료될 때까지 위 재접속 처리를 반복한다.
- Wi-Fi 연결 실패 및 재접속 처리는 운전 상태와 독립적으로 수행한다.
- 재접속 처리 중에도 습도 측정, 운전 제어, 자동 제습 및 보호 기능은 정상적으로 수행한다.

#### 2.16.5 연결 상태 표시

Wi-Fi 연결 과정에 따른 RGB LED 표시는 다음과 같다.

| Wi-Fi 상태 | Wi-Fi RGB LED |
|---|---|
| 접속 정보 없음 | RED |
| 미접속 | RED |
| 연결 시도 중 | BLUE |
| 연결 완료 | GREEN |
| 연결 실패 | RED |

Wi-Fi RGB LED의 상세 표시 사양은 `FUNC-012 상태 표시`에 따른다.

#### 2.16.6 전원 재인가

- 시스템 전원이 다시 인가되면 저장된 Wi-Fi 접속 정보를 불러온다.
- 유효한 Wi-Fi 접속 정보가 존재하는 경우 자동으로 Wi-Fi 연결을 시도한다.
- 연결을 시도하는 동안 Wi-Fi RGB LED를 BLUE로 표시한다.
- 연결 성공 시 GREEN, 연결 실패 시 RED로 표시한다.
- 저장된 Wi-Fi 접속 정보가 없는 경우 Wi-Fi RGB LED를 RED로 표시한다.
- 정상적으로 Wi-Fi 설정을 완료한 이후에는 전원 재인가 시 Wi-Fi 접속 정보를 다시 입력하지 않아도 자동으로 연결할 수 있도록 한다.

### 2.17 FUNC-016 상태 정보 송신

제습기의 현재 동작 상태 및 측정 정보를 외부 시스템으로 송신한다.

Wi-Fi 네트워크에 정상적으로 연결된 상태에서 현재 습도, 목표 습도, 운전 상태, 제습 상태 및 보호 상태 등의 정보를 외부 시스템으로 송신한다.

외부 시스템과의 통신 상태와 관계없이 제습기의 기본 제어 및 보호 기능은 독립적으로 동작한다.

#### 2.17.1 송신 정보

외부 시스템으로 송신하는 상태 정보는 다음과 같다.

| 정보 | 설명 |
|---|---|
| 현재 습도 | 습도 센서에서 측정한 현재 상대습도 |
| 목표 습도 | 현재 설정되어 있는 목표 습도 |
| 운전 상태 | 운전 ON/OFF 상태 |
| 제습 상태 | 현재 실제 제습 동작 여부 |
| 만수 상태 | 물탱크 만수 여부 |
| 결빙 보호 상태 | 결빙 보호 동작 여부 |
| 과열 보호 상태 | 과열 보호 동작 여부 |
| 센서 이상 상태 | 센서 이상 발생 여부 및 이상 센서 정보 |
| 냉각부 온도 | 펠티어 냉각부의 현재 온도 |
| 방열부 온도 | 펠티어 방열부의 현재 온도 |

송신 정보의 데이터 형식 및 세부 구조는 별도 통신 사양에서 정의한다.

#### 2.17.2 주기 상태 송신

- Wi-Fi 네트워크에 정상적으로 연결된 상태에서 상태 정보를 주기적으로 송신한다.
- 상태 정보 송신 주기는 별도 통신 사양에서 정의한다.
- 주기 송신 시 송신 시점의 최신 상태 정보를 사용한다.
- Wi-Fi가 연결되어 있지 않은 경우 상태 정보를 송신하지 않는다.
- Wi-Fi 연결이 복구된 경우 상태 정보 송신을 재개한다.

#### 2.17.3 상태 변경 시 송신

제습기의 주요 상태가 변경된 경우 변경된 상태 정보를 외부 시스템으로 송신한다.

주요 상태 변경 대상은 다음과 같다.

- 운전 ON/OFF 변경
- 목표 습도 변경
- 제습 동작 시작 및 정지
- 만수 상태 발생 및 해제
- 결빙 보호 발생 및 해제
- 과열 보호 발생 및 해제
- 센서 이상 발생 및 해제

상태 변경 시 송신은 주기 상태 송신과 독립적으로 수행할 수 있도록 한다.

#### 2.17.4 송신 실패

- 상태 정보 송신에 실패한 경우 제습기의 기본 운전 및 보호 기능에 영향을 주지 않는다.
- 송신 실패로 인해 펠티어 및 팬의 제어를 중지하지 않는다.
- Wi-Fi 연결이 끊어진 경우 `FUNC-015 Wi-Fi 연결`에 따라 재접속을 수행한다.
- Wi-Fi 연결이 복구된 경우 최신 상태 정보를 외부 시스템으로 송신한다.
- 과거에 송신하지 못한 주기 상태 정보를 모두 저장하여 재송신하는 기능은 기본 기능에 포함하지 않는다.

#### 2.17.5 상태 정보 갱신

- 외부 시스템으로 송신하는 정보는 시스템 내부에서 관리하는 최신 상태값을 사용한다.
- 센서 측정값이 갱신된 경우 최신 정상 측정값을 상태 정보에 반영한다.
- 센서 이상이 발생한 경우 해당 센서의 이상 상태를 상태 정보에 포함한다.
- 본체 조작 또는 원격 제어에 의해 상태가 변경된 경우 변경된 값을 상태 정보에 반영한다.

#### 2.17.6 통신 독립성

- 상태 정보 송신 기능은 제습기의 기본 운전 및 보호 기능과 독립적으로 동작한다.
- 외부 시스템과 통신할 수 없는 상태에서도 본체를 이용한 운전 및 목표 습도 설정이 가능하도록 한다.
- 외부 시스템과의 통신 장애는 시스템 에러 상태로 처리하지 않으며 에러 LED를 점등하지 않는다.
- Wi-Fi 연결 상태는 Wi-Fi RGB LED를 통해 별도로 표시한다.

### 2.18 FUNC-017 원격 운전 제어

외부 시스템으로부터 운전 ON/OFF 명령을 수신하여 제습기의 운전 상태를 원격으로 제어한다.

원격 운전 제어는 본체의 운전 버튼을 통한 운전 제어와 동일한 운전 상태를 사용하며, 원격 명령에 의해 운전 상태가 ON으로 변경되더라도 실제 제습 동작 여부는 현재 습도, 목표 습도 및 보호 상태에 따라 결정한다.

#### 2.18.1 원격 운전 명령

외부 시스템으로부터 다음 운전 명령을 수신한다.

| 원격 명령 | 동작 |
|---|---|
| ON | 운전 상태를 ON으로 변경한다. |
| OFF | 운전 상태를 OFF로 변경한다. |

- 원격 운전 명령은 Wi-Fi 및 외부 시스템과의 통신이 가능한 상태에서 수신한다.
- 수신한 명령의 유효성을 확인한 후 운전 상태에 반영한다.
- 유효하지 않은 운전 명령은 운전 상태에 반영하지 않는다.

#### 2.18.2 원격 운전 ON

원격으로 운전 ON 명령을 수신한 경우 다음과 같이 처리한다.

- 운전 상태를 ON으로 변경한다.
- 현재 습도와 목표 습도를 확인한다.
- 만수, 결빙, 과열 및 센서 이상 등의 보호 상태를 확인한다.
- 보호 상태가 없고 제습 조건을 만족하는 경우 자동 제습 제어에 따라 제습 동작을 시작한다.
- 제습 조건을 만족하지 않는 경우 운전 상태는 ON으로 유지하고 제습 대기 상태로 전환한다.
- 보호 상태가 존재하는 경우 운전 상태는 ON으로 유지하되 제습 동작은 수행하지 않는다.
- 보호 상태에 의한 제습 일시 정지 상태에서는 `FUNC-012 상태 표시`에 따라 제습 LED를 점멸한다.

#### 2.18.3 원격 운전 OFF

원격으로 운전 OFF 명령을 수신한 경우 다음과 같이 처리한다.

- 운전 상태를 OFF로 변경한다.
- 제습 동작 중인 경우 펠티어 소자를 정지한다.
- 흡기 팬을 정지한다.
- 방열 팬은 필요한 후속 방열 동작을 수행한 후 정지한다.
- 제습 상태 표시 LED를 소등한다.
- 습도 및 온도 등의 센서 측정은 계속 수행한다.
- Wi-Fi 연결 및 외부 시스템과의 통신은 계속 유지한다.
- 만수 및 시스템 이상 상태의 감시는 운전 OFF 상태에서도 계속 수행한다.

#### 2.18.4 본체 운전 제어와의 관계

본체 운전 버튼과 원격 운전 제어는 동일한 운전 상태를 제어한다.

- 본체에서 운전 상태를 변경한 경우 변경된 상태를 시스템에 즉시 반영한다.
- 원격에서 운전 상태를 변경한 경우 변경된 상태를 본체 동작에 즉시 반영한다.
- 본체 조작과 원격 명령 사이에 별도의 우선순위를 두지 않으며 마지막으로 정상 처리된 운전 명령을 적용한다.
- 운전 상태가 변경된 경우 변경된 상태를 외부 시스템으로 송신한다.

#### 2.18.5 보호 상태에서의 원격 제어

만수, 결빙, 과열 또는 센서 이상 등의 보호 상태에서도 원격 운전 명령을 수신할 수 있다.

- 보호 상태에서 ON 명령을 수신한 경우 운전 상태는 ON으로 변경할 수 있으나 제습 동작은 시작하지 않는다.
- 보호 상태가 해제된 후 운전 상태가 ON이고 제습 조건을 만족하는 경우 자동으로 제습 동작을 시작한다.
- 보호 상태에서 OFF 명령을 수신한 경우 운전 상태를 OFF로 변경한다.
- 운전 상태가 OFF인 경우 보호 상태가 해제되더라도 자동으로 제습 동작을 시작하지 않는다.

#### 2.18.6 통신 단절 시 동작

- Wi-Fi 또는 외부 시스템과의 통신이 끊어진 경우 현재 운전 상태를 유지한다.
- 통신 단절만을 이유로 운전 상태를 OFF로 변경하지 않는다.
- 통신이 불가능한 상태에서도 본체 운전 버튼을 통한 운전 제어는 정상적으로 수행한다.
- 통신이 복구되면 현재 운전 상태를 외부 시스템으로 송신하여 상태를 동기화한다.

### 2.19 FUNC-018 원격 습도 설정

외부 시스템으로부터 목표 습도 설정값을 수신하여 제습기의 목표 습도를 원격으로 변경한다.

원격으로 설정된 목표 습도는 본체에서 설정한 목표 습도와 동일한 설정값으로 관리하며, 변경된 목표 습도는 자동 제습 제어에 반영한다.

#### 2.19.1 원격 목표 습도 설정

- 외부 시스템으로부터 목표 습도 설정값을 수신한다.
- 원격 목표 습도 설정은 Wi-Fi 및 외부 시스템과의 통신이 가능한 상태에서 수행한다.
- 수신한 목표 습도 설정값의 유효성을 확인한다.
- 유효한 설정값인 경우 현재 목표 습도를 해당 값으로 변경한다.
- 목표 습도는 본체에서 설정 가능한 범위와 동일한 범위로 제한한다.
- 목표 습도는 5% 단위의 설정값만 허용한다.
- 설정 가능한 범위를 벗어나거나 유효하지 않은 값은 적용하지 않는다.

목표 습도의 최솟값, 최댓값 및 기본값은 별도 제어 사양에서 정의한다.

#### 2.19.2 설정값 적용

원격으로 목표 습도가 변경된 경우 다음과 같이 처리한다.

- 변경된 목표 습도를 시스템에 즉시 반영한다.
- 운전 상태가 ON인 경우 변경된 목표 습도와 현재 습도를 비교하여 제습 조건을 다시 판단한다.
- 변경된 목표 습도에 따라 제습 조건을 만족하는 경우 자동 제습 제어에 따라 제습 동작을 수행한다.
- 제습 조건을 만족하지 않는 경우 제습 동작을 대기 또는 정지 상태로 전환한다.
- 만수, 결빙, 과열 또는 센서 이상 등의 보호 상태가 존재하는 경우 목표 습도는 변경하되 제습 동작은 수행하지 않는다.
- 실제 제습 동작은 `FUNC-005 자동 제습 제어`에 따른다.

#### 2.19.3 본체 습도 설정과의 관계

본체의 습도 설정 터치 버튼과 원격 습도 설정은 동일한 목표 습도값을 제어한다.

- 본체에서 목표 습도를 변경한 경우 변경된 값을 시스템에 즉시 반영한다.
- 원격에서 목표 습도를 변경한 경우 변경된 값을 시스템에 즉시 반영한다.
- 본체 설정과 원격 설정 사이에 별도의 우선순위를 두지 않으며 마지막으로 정상 처리된 설정값을 적용한다.
- 본체 또는 원격에서 목표 습도가 변경된 경우 최신 목표 습도값을 외부 시스템으로 송신한다.

#### 2.19.4 설정값 표시

- 원격으로 목표 습도가 변경된 경우 변경된 목표 습도를 2자리 7-Segment에 일정 시간 동안 표시한다.
- 목표 습도 표시 시간이 경과하면 현재 습도 표시로 복귀한다.
- 목표 습도 표시 중 본체에서 목표 습도가 변경된 경우 가장 최근에 변경된 목표 습도를 표시한다.
- 습도 표시의 상세 동작은 `FUNC-004 습도 표시`에 따른다.

#### 2.19.5 설정값 저장

- 원격으로 변경된 목표 습도는 본체에서 변경된 목표 습도와 동일하게 저장 대상으로 관리한다.
- 목표 습도 변경 후 일정 시간 동안 추가 변경이 없는 경우 최종 설정값으로 확정한다.
- 확정된 목표 습도는 비휘발성 메모리에 저장한다.
- 연속적으로 목표 습도가 변경되는 경우 마지막으로 확정된 설정값을 저장한다.
- 설정값 저장 및 복원에 대한 상세 동작은 `FUNC-019 설정값 저장`에 따른다.

#### 2.19.6 통신 단절 시 동작

- Wi-Fi 또는 외부 시스템과의 통신이 끊어진 경우 현재 설정된 목표 습도를 유지한다.
- 통신 단절로 인해 목표 습도를 기본값으로 변경하지 않는다.
- 통신이 불가능한 상태에서도 본체의 습도 설정 터치 버튼을 통한 목표 습도 변경은 정상적으로 수행한다.
- 통신이 복구되면 현재 목표 습도값을 외부 시스템으로 송신하여 상태를 동기화한다.

### 2.20 FUNC-019 설정값 저장

시스템에서 사용하는 설정값을 비휘발성 메모리에 저장하고, 시스템 전원이 차단된 후 다시 인가되더라도 마지막으로 저장된 설정값을 복원한다.

설정값 저장은 불필요한 비휘발성 메모리 쓰기를 줄이기 위해 설정 변경이 확정된 경우에 수행한다.

#### 2.20.1 저장 대상

비휘발성 메모리에 저장하는 설정값은 다음과 같다.

| 설정값 | 저장 여부 | 설명 |
|---|---|---|
| 목표 습도 | 저장 | 마지막으로 확정된 목표 습도를 저장한다. |
| Wi-Fi SSID | 저장 | 설정된 Wi-Fi 네트워크 정보를 저장한다. |
| Wi-Fi 인증 정보 | 저장 | Wi-Fi 접속에 필요한 인증 정보를 저장한다. |
| 운전 ON/OFF 상태 | 저장하지 않음 | 전원 재인가 시 항상 OFF로 초기화한다. |
| 측정 습도 및 온도 | 저장하지 않음 | 시스템 동작 중 실시간으로 측정한다. |
| 만수 및 에러 상태 | 저장하지 않음 | 시스템 초기화 후 센서 상태를 통해 다시 판단한다. |

#### 2.20.2 목표 습도 저장

- 본체 또는 원격 제어를 통해 목표 습도가 변경된 경우 변경된 값을 시스템에 즉시 반영한다.
- 목표 습도 변경 후 일정 시간 동안 추가 변경이 없는 경우 해당 값을 최종 설정값으로 확정한다.
- 최종 설정값으로 확정된 목표 습도를 비휘발성 메모리에 저장한다.
- 목표 습도가 연속적으로 변경되는 경우 변경할 때마다 저장하지 않고 마지막으로 확정된 값만 저장한다.
- 저장 대기 시간은 별도 제어 사양에서 정의한다.

#### 2.20.3 Wi-Fi 설정값 저장

- `FUNC-014 Wi-Fi 설정`을 통해 Wi-Fi 설정이 완료된 경우 Wi-Fi 접속 정보를 비휘발성 메모리에 저장한다.
- Wi-Fi 접속 정보에는 SSID 및 인증 정보를 포함한다.
- Wi-Fi 설정값은 일반적인 상태 정보 송신을 통해 외부로 노출하지 않는다.
- Wi-Fi RESET 기능이 수행된 경우 저장된 Wi-Fi 접속 정보를 삭제한다.
- Wi-Fi 설정 초기화는 목표 습도 설정값에 영향을 주지 않는다.

#### 2.20.4 설정값 복원

시스템 전원 인가 및 초기화 시 비휘발성 메모리에 저장된 설정값을 확인한다.

- 유효한 목표 습도 설정값이 존재하는 경우 해당 값을 현재 목표 습도로 복원한다.
- 저장된 목표 습도가 없거나 유효하지 않은 경우 기본 목표 습도를 적용한다.
- 유효한 Wi-Fi 접속 정보가 존재하는 경우 해당 정보를 이용하여 `FUNC-015 Wi-Fi 연결`을 수행한다.
- Wi-Fi 접속 정보가 존재하지 않는 경우 `FUNC-014 Wi-Fi 설정`에 따라 Wi-Fi 설정 모드로 진입할 수 있도록 한다.
- 운전 상태는 저장된 설정값과 관계없이 OFF로 초기화한다.

#### 2.20.5 저장 데이터 이상

- 비휘발성 메모리에서 읽은 설정값의 유효성을 확인한다.
- 저장된 목표 습도가 설정 가능한 범위를 벗어난 경우 해당 값을 사용하지 않고 기본 목표 습도를 적용한다.
- Wi-Fi 접속 정보가 없거나 유효하지 않은 경우 해당 정보를 이용한 Wi-Fi 연결을 수행하지 않는다.
- 설정값 이상이 발생하더라도 제습기의 기본 초기화 및 보호 기능을 수행할 수 있도록 한다.

#### 2.20.6 전원 차단 및 재인가

전원 차단 후 다시 전원이 인가된 경우 다음과 같이 시스템 상태를 복원한다.

| 항목 | 전원 재인가 후 동작 |
|---|---|
| 목표 습도 | 마지막으로 저장된 설정값 복원 |
| Wi-Fi 설정 | 마지막으로 저장된 접속 정보 복원 |
| 운전 상태 | OFF로 초기화 |
| 현재 습도 | 센서에서 새로 측정 |
| 냉각부/방열부 온도 | 센서에서 새로 측정 |
| 만수 상태 | 수위 센서를 통해 새로 판단 |
| 보호 및 에러 상태 | 각 센서 상태를 확인하여 새로 판단 |

설정값 복원이 완료된 후 시스템의 각 기능을 정상적으로 초기화한다.
